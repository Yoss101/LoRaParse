What is LoRaScan?

Lorascan is a long-term LoRa spectrum band scanner and interference analyzer designed for the 902–928 MHz US ISM band. It runs on hardware like a Raspberry Pi or USB-SPI sticks using an actual LoRa radio to capture real-world interference.
