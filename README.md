# LoRaScan Database Viewer

A lightweight, browser-based database viewer built specifically to parse and analyze SQLite logs generated by **LoRaScan**. It runs entirely in the browser using WebAssembly (`sql.js`), meaning you can load your database files locally without uploading them to a server.

## What it does
This tool opens LoRaScan `.db` or `.sqlite` files, extracts the underlying wideband spectrum metrics, and instantly highlights critical channel performance. It calculates true weighted global occupancy and isolates the quietest and busiest channels in your region while automatically filtering out out-of-band noise or amateur radio repeater segments.

---

## Simple Feature List

| Feature Component | Operation Type | Purpose |
| :--- | :--- | :--- |
| **Local File Loader** | Dynamic WASM Buffer | Lets you drag/drop or select custom local `.db` telemetry files safely inside the browser context layout. |
| **Channel Highlights** | Dynamic Spectrum Math | Automatically extracts and flags the Top 3 Quietest and Busiest channels (e.g., 923.4 MHz, 910.6 MHz). |
| **Band Isolation** | Algorithmic Exclusion | Automatically masks out-of-band repeater noise (902.0–903.25 MHz) from messing up spectrum averages. |
| **Interactive Grid** | Dynamic Schema Layout | Dynamically adapts its table view arrays to match any LoRaScan table catalog (e.g., `energy`, `runs`). |

---

## Quick Start
1. Open `index.html` in any modern web browser.
2. Click **Load Custom DB File** at the top of the interface page layout.
3. Select your local LoRaScan database file (e.g., `site.db`).
4. Read the summary metrics card layouts instantly or switch tables via the dropdown menu to inspect row entries.
